## Overview

P.A.N.I AI Recruitment is a AI recruitment project in the TheAdhithyanKR/pani-ai-recruitment repository. AI-assisted recruitment platform prototype built with TypeScript, Vite, and a local server/database setup.

The README was written from the repository contents, including its manifest files, source tree, and available project metadata. The primary manifest is `package.json`, and the commands below are taken from its scripts.
